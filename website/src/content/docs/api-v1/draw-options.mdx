## `ease`

`ease` shapes the whole timeline, from 0 to 1. It decides whether the drawing rushes the start or settles into the finish.

Eight curves ship with the package, and `easings` exports them as functions if you want to inspect or reuse one:

| Name | Shape |
| --- | --- |
| `linear` | No shaping at all |
| `easeIn` | Slow start, fast finish |
| `easeOut` | Fast start, slow finish |
| `easeInOut` | Slow both ends, fast in the middle |
| `easeOutCubic` | The default. A soft, quick settle |
| `easeInOutCubic` | Symmetric, gentler than `easeInOut` |
| `easeOutQuart` | A sharper version of `easeOut` |
| `easeOutBack` | Overshoots slightly past the end, then settles |

Any function of the form `(t: number) => number` works too. It is used verbatim, with no validation of range or monotonicity.

```ts
draw(svg, { ease: (t) => t * t * (3 - 2 * t) });  // smoothstep
```

An unrecognised string falls back rather than throwing, so a typo gives you the default curve and no error.

## `strokeEase`

Where `ease` moves through the timeline, `strokeEase` moves within a single stroke. The two compose: the timeline position is eased globally, then each stroke's slice of it is eased again.

```ts
draw(svg, {
    ease: 'linear',        // even hand-offs between strokes
    strokeEase: 'easeOut', // but each stroke itself finishes fast
});
```

Leave `strokeEase` linear when you want constant pen speed within each stroke, which is what makes `type: 'speed'` read as a real pen.

## `reveal`

Fills are hidden at the start and brought back as the drawing progresses. Three strategies:

| Value | Behaviour |
| --- | --- |
| `'end'` (default) | Every fill fades together, starting at `revealStart` |
| `'stroke'` | Each fill fades in behind its own stroke, over that stroke's last 40% |
| `'none'` | Fills are never hidden and never animated |

`reveal: 'stroke'` is the one that makes diagrams read properly, because a box is filled at the moment its outline finishes rather than all at once at the end. The `diagram` preset uses it.

Fills on shapes that never got an outline, because they are fill-only and `outline` is off, fall back to the `end` behaviour even under `reveal: 'stroke'`.

## `text`

| Value | Behaviour |
| --- | --- |
| `'fade'` (default) | Labels fade in over the reveal window |
| `'type'` | Labels appear letter by letter |
| `'none'` | Labels are left untouched |

`type` works against a character budget shared across the whole SVG, walked in document order. It is a reveal, not a typing effect: every label reaches its full text at once, they just do it in sequence. `image` and `foreignObject` always fade, since there is no text to type.

## `pen`

```ts
draw(svg, { pen: true });                          // default circle nib
draw(svg, { pen: { radius: 5, color: '#2f6a5c' } });
draw(svg, { pen: { element: myNib } });           // bring your own
```

The nib rides the tip of whichever stroke is mid-draw and hides when there is none. It only attaches to strokes it can dash, so dashed artwork gets no nib. Full detail on [the pen nib](/docs/v1/pen).

## `sketchy`

```ts
draw(svg, { sketchy: true });
draw(svg, { sketchy: { roughness: 2.4, seed: 7, step: 4 } });
```

Resamples each shape's outline and jitters the samples with a seeded generator, so the same `seed` always produces the same wobble. Shapes other than `path` are replaced with a generated path, and `destroy()` puts the originals back. See [hand-drawn mode](/docs/v1/sketchy).

## `reducedMotion`

`respect` is the default and it is a real behaviour, not a hint: when the user prefers reduced motion, every run jumps straight to the finished frame, `start` never fires and `onStart` never runs. `complete` still fires, so code waiting on that keeps working.

Set `reducedMotion: 'ignore'` to animate regardless. Only do that if your page has its own reason to override the preference.

## Combining options

Options compose freely, and `presets` is just shorthand for a combination that already works:

```ts
import { presets } from '@penwell/draw-on/core';

draw(svg, { ...presets.diagram, duration: 3000, delay: 200 });
```

One ordering caveat worth repeating: under `type: 'speed'`, `duration` is ignored entirely and the timeline length comes from the geometry.
