# Start here (1.0)

1.0 is a rewrite of the engine, not a feature bump. Vivus is gone, timing is in milliseconds, and the handle you get back can pause, reverse, scrub by time and change speed while it plays.

<Callout type="warning" title="Two versions live on this site">
    Everything under **Draw-On 1.0** and **Draw-On 1.0 Reference** documents the current
    release. The groups below them document 0.1.x, which still installs and still works.
    If you are starting fresh, ignore those. If you are upgrading, read
    [Migrating from 0.1.x](/docs/v1/migration) first.
</Callout>

## The smallest useful program

```ts
import { draw } from '@penwell/draw-on/core';

const drawing = draw('#logo', { duration: 1800, type: 'stagger' });

await drawing.play();
```

`draw()` takes an element, a wrapper containing one, or a selector. It reads the SVG's own stroke geometry, gives fill-only shapes a temporary outline so there is something to draw, then fades the fills and labels back in as the strokes finish.

## Pick a preset, then adjust it

`presets` is five tuned bundles. Spread one and override whatever you disagree with, rather than starting from a blank options object.

```ts
import { draw, presets } from '@penwell/draw-on/core';

draw(svg, { ...presets.diagram, duration: 3000 });
```

## Take control of the handle

The handle is the part that changed most. Every method below works while the animation is running.

<LiveDemo
    title="Playback controls, live speed and the event stream"
    description="Play, pause, resume, reverse, restart, seek, change speed mid-flight, and watch the events arrive."
    sourceId="engine-handle"
    wide
/>

```ts
const drawing = draw(svg, { duration: 3000 });

const off = drawing.on('complete', () => console.log('done'));

drawing.playbackRate = 2;   // speed it up without restarting
drawing.seek(0.4);          // jump somewhere
await drawing.reverse();    // undraw it
off();                      // stop listening
drawing.destroy();          // restore the SVG exactly as it was
```

## Two entry points you have not used yet

**React.** `useDrawOn` takes triggers, so a drawing can start on mount, on scroll, on hover or on click, or be driven entirely by a slider.

**Web Component.** `<draw-on>` means a page with no framework at all, or a CMS template, can animate an SVG from markup alone.

Both are covered in the reference. If you came from 0.1.x, read [Migrating from 0.1.x](/docs/v1/migration) before anything else.
