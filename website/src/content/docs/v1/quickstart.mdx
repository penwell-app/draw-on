# Quickstart (1.0)

Install, draw one SVG, then drive it. Both flavours below run the same engine; pick whichever matches your page.

## Install

```bash
npm install @penwell/draw-on
```

1.0 has no runtime dependencies. React stays an optional peer, and only the `/react` entry point needs it.

## Plain JavaScript

Point `draw()` at a selector and it takes care of the rest.

<Callout type="note" title="The SVG has to be inline">
    `draw()` reads real geometry, so the `<svg>` must already be in the document.
    Markup fetched after the fact needs `mount()` or `loadSvg()` first.
</Callout>

```html
<svg id="logo" viewBox="0 0 200 80">
  <path d="M20 60 C60 20 100 70 180 30" fill="none" stroke="#27241a" stroke-width="4" />
</svg>
```

```ts
import { draw } from '@penwell/draw-on/core';

const drawing = draw('#logo', { duration: 1800, type: 'stagger' });

await drawing.play();
```

That is the whole thing. Strokes animate on, and anything with a fill fades in behind them.

## React

`useDrawOn` mounts the SVG and hands back the same handle.

```tsx
import { useDrawOn } from '@penwell/draw-on/react';

function Logo() {
    const api = useDrawOn({
        svg: markup,
        duration: 1800,
        type: 'stagger',
        trigger: 'auto',
    });

    return <div ref={api.ref} style={{ maxWidth: 420 }} />;
}
```

`trigger` decides when it starts. `auto` is the default, `inView` waits for the element to scroll into view, `hover` and `click` restart on the event, and `manual` waits for you.

If you would rather write the SVG as JSX, use the component:

```tsx
import { DrawOn } from '@penwell/draw-on/react';

<DrawOn duration={1800} type="stagger">
    <svg viewBox="0 0 200 80">
        <path d="M20 60 C60 20 100 70 180 30" fill="none" stroke="#27241a" strokeWidth="4" />
    </svg>
</DrawOn>
```

## Add a scrubber

Progress is a plain number from 0 to 1. `seek()` jumps to it and `on('progress')` reports it, which is all a slider needs.

```tsx
const drawing = draw(svg, { autoplay: false });
const off = drawing.on('progress', setProgress);

input.addEventListener('input', (event) => drawing.seek(Number(event.target.value)));
```

## Record the result

`recordDrawToWebM` drives the drawing for you while `MediaRecorder` captures the canvas, and `recordFrames` gives you PNG frames instead when you want to build a GIF or a sprite sheet.

```ts
import { downloadBlob, recordDrawToWebM } from '@penwell/draw-on/core';

const blob = await recordDrawToWebM(drawing.el, drawing.setProgress, {
    width: 1280,
    height: 640,
});

downloadBlob(blob, 'draw-on.webm');
```
