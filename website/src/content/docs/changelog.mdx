## Versioning

The package follows semantic versioning:

- **Major** — a breaking change to the public API or to the recorded output.
- **Minor** — new capability, backwards compatible: a new option, a new helper, a
  new entry point.
- **Patch** — fixes, documentation and performance work that does not change how
  the API behaves.

## Upgrading

There are no breaking changes within `0.1.x`. If you are coming from Vivus
directly, the [comparison page](/docs/vivus-comparison) has the mapping table, and
the two behavioural differences to expect — fills drawing as outlines first, and
labels fading in at the end — are both controlled by
[`revealStart` and `revealMs`](/docs/api/drawing-options).
